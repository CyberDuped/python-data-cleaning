# Security-Aware Data Cleaning Pipeline (Python)

## Overview
This project demonstrates a reproducible data cleaning workflow using Python and Pandas. The dataset contains restaurant health inspection scores from 2016–2019. The goal is to clean, validate, and prepare the data for analysis while applying secure and reliable data-handling practices.

## Skills Demonstrated
- Python (Pandas)
- Data Cleaning & Transformation
- Data Validation
- EDA (Jupyter Notebook)
- GitHub Project Organization

## Folder Structure
Python-Data-Cleaning/

├── src/

## Pipeline Steps
1. Load & inspect data  
2. Clean column names  
3. Handle missing values  
4. Convert data types  
5. Remove duplicates  
6. Normalize text fields  
7. Apply validation rules  
8. Export cleaned dataset  

## How to Run
pip install -r requirements.txt  
python src/cleaning_pipeline.py  

## Results
- Missing values handled  
- Types corrected  
- Duplicates removed  
- Invalid scores filtered  
- Clean dataset ready for analysis
